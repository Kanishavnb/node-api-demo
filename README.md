# Node API Demo

A small Node.js server that returns users as JSON, and a web page that loads them with fetch.

## How to run
1. Install Node.js
2. Run node server.js
3. Open local-api.html in a browser and click Load users

## What it shows
- A Node.js server using the http module
- A JSON API endpoint at /api/users
- A CORS header so the browser allows the request
- A front-end page using fetch with async/await and error handling
